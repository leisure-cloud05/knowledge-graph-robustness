# PC5253 Part A: ConceptNet knowledge graph

This project freezes a 1,000-node English graph derived from the ConceptNet 5.7.0 assertions dump. The authoritative graph files are `data/processed/nodes.csv` and `data/processed/edges.csv`; `data/processed/graph_metadata.json` records their provenance, validation results, and SHA-256 hashes. The `candidate_*` files remain available as the sampling output used to make the frozen copy.

## Source and dates

The [official ConceptNet downloads page](https://github.com/commonsense/conceptnet5/wiki/Downloads) identifies the 5.7.0 assertions as a gzip-compressed, tab-separated file. Its [direct download URL](https://s3.amazonaws.com/conceptnet/downloads/2019/edges/conceptnet-assertions-5.7.0.csv.gz) is for `conceptnet-assertions-5.7.0.csv.gz`. Place this file at `data/raw/conceptnet-assertions-5.7.0.csv.gz`. The `data/raw/` directory is ignored by Git; do not commit the raw dump.

The original plan was to collect ConceptNet data through paginated API requests. Actual API tests repeatedly encountered HTTP 502 responses, so the project followed its fallback path and used the official ConceptNet 5.7.0 offline assertions file instead. The existing API helper supports only a single-page test request; this project does not implement or claim API pagination.

The local raw file is 497,963,447 bytes and has SHA-256 `accd65fe94038584295574ddc26e1500c1919c8c4532bf771811cafd0948af7e`. Its local creation and last-modified dates are both **2026-10-28**, recorded here as the download/landing date; a separate download log was not checked. The graph was built on **2026-10-29**. These are distinct dates; the earlier candidate report's `collection_date` refers to the graph run.

## Environment and reproduction

Use the `PC5253-KG` Conda environment with Python 3.11 (the recorded environment used Python 3.11.16). From the project root, create it if needed and install the pinned packages:

```powershell
conda create -n PC5253-KG python=3.11
conda run -n PC5253-KG python -m pip install -r requirements.txt
```

With the raw file in place, the existing entry point reproduces the **candidate** CSV and candidate metadata:

```powershell
conda run -n PC5253-KG python -B -m scripts.sample_candidate
```

Run it from the project root. It reads the large compressed dump twice and writes `data/processed/candidate_nodes.csv`, `candidate_edges.csv`, and `candidate_metadata.json`, replacing those candidate files if they already exist. It does not write the frozen `nodes.csv` or `edges.csv`. The reported sampling run took 1,109.04 seconds on the original machine.

The three `candidate_*` files are ignored by `.gitignore` and must be generated by that script when reproducing the sample. The frozen `nodes.csv` and `edges.csv` are delivered with the project. After checking a newly generated candidate graph, use PowerShell from the project root to copy its CSV files byte for byte into the formal filenames (this overwrites the delivered copies):

```powershell
Copy-Item -LiteralPath 'data/processed/candidate_nodes.csv' -Destination 'data/processed/nodes.csv'
Copy-Item -LiteralPath 'data/processed/candidate_edges.csv' -Destination 'data/processed/edges.csv'
```

Compare the copied files' SHA-256 hashes with the frozen hashes recorded below and in `graph_metadata.json`. A mismatch means the reproduced output differs from this frozen graph:

```powershell
$nodesHash = (Get-FileHash -Algorithm SHA256 -LiteralPath 'data/processed/nodes.csv').Hash.ToLowerInvariant()
$edgesHash = (Get-FileHash -Algorithm SHA256 -LiteralPath 'data/processed/edges.csv').Hash.ToLowerInvariant()
if ($nodesHash -ne 'ee3707a806946be17e7916c49234541b9bcb981bec4a486a06b79344c921ec51') { throw "nodes.csv SHA-256 mismatch: $nodesHash" }
if ($edgesHash -ne '837510ddb395f905e9bb5605e39bac1753d2a12fef74f6068e61c21ae436f0e8') { throw "edges.csv SHA-256 mismatch: $edgesHash" }
```

Run the pipeline's single test file with:

```powershell
conda run -n PC5253-KG python -B -m pytest tests/test_data_pipeline.py
```

## Sampling and cleaning

The 15 seeds are `/c/en/animal`, `/c/en/dog`, `/c/en/cat`, `/c/en/bird`, `/c/en/fish`, `/c/en/pet`, `/c/en/food`, `/c/en/water`, `/c/en/house`, `/c/en/person`, `/c/en/child`, `/c/en/school`, `/c/en/book`, `/c/en/car`, and `/c/en/road`. `max_nodes=1000`.

The sampler normalizes and retains every seed, then fills remaining slots with the lexicographically smallest distinct English concepts directly adjacent to any seed. The first full scan chooses nodes; the second keeps assertions whose cleaned endpoints are both selected. Cleaning keeps valid English base concept paths, accepts finite non-negative weights, removes self-loops, treats edges as undirected, merges repeated and reversed edges, unions their relation categories, and keeps the maximum weight per node pair. This gives the same selected graph regardless of assertion row order. All weights present in this frozen CSV are positive.

## Frozen files and validation

`nodes.csv` has one column, `concept`, containing a base path such as `/c/en/dog`. `edges.csv` has `source` and `target` (the two normalized endpoints of an undirected edge), `relation` (a JSON array of ConceptNet relation paths, including paths such as `/r/dbpedia/genus`), and `weight` (the maximum finite non-negative weight retained for that pair; every weight in this frozen CSV is positive). Each formal CSV is byte-identical to its corresponding candidate CSV.

| File | SHA-256 |
| --- | --- |
| `data/processed/nodes.csv` | `ee3707a806946be17e7916c49234541b9bcb981bec4a486a06b79344c921ec51` |
| `data/processed/edges.csv` | `837510ddb395f905e9bb5605e39bac1753d2a12fef74f6068e61c21ae436f0e8` |

An independent read of the formal CSV found **1,000 distinct nodes** and **1,325 distinct undirected edges**, with no self-loops, duplicate node pairs, or endpoints outside the node table. All 15 seeds are present. The NetworkX graph has **one connected component**, **zero isolates**, and a largest-component ratio of **100%**. In that component, **93,449 unordered node pairs** have shortest-path distance exactly 2 and **200,359** have distance exactly 3. The existing feasibility rule requires at least 75 pairs at each distance, so a mixed set of 150 queries (75 of each kind) is feasible; no query set is generated here.

A user-confirmed, AI-assisted review of 20 sampled edges is recorded in the [manual edge audit](docs/manual_edge_audit.md). It is a targeted sample review rather than an estimate of full-graph accuracy.

## Limitations

`/c/en/person` has degree **355**, so it can dominate connectivity and short-path candidate counts. Lexicographic truncation favors alphabetically early neighbor identifiers; this graph is deterministic but is not a random or representative sample of ConceptNet.
